# Privacy policy — Library Finder

Library Finder does not collect, store, or transmit any personal data.

## What the extension reads

On supported book retailer pages (currently amazon.com), the extension reads the visible text of the page to look for an ISBN. It does not read pages on any other site, and it does not read account information, purchase history, payment details, or anything you type.

## What the extension sends

If an ISBN is found, the extension sends only that ISBN number to [Open Library](https://openlibrary.org)'s public API, to look up the book's title, author, and free digital lending availability. No other page content, browsing history, or personal identifiers are sent anywhere.

## What the extension stores

Nothing. The extension has no local storage, no accounts, and no analytics or tracking of any kind.

## Third parties

The only third-party service this extension talks to is Open Library's public API (openlibrary.org), which is free and requires no account or API key. Its own privacy policy applies to that request: https://openlibrary.org/privacy

## Changes

If this policy changes, the update will be reflected in this file in the project's GitHub repository: https://github.com/aribajahan/library-finder
