## Extension name
Library Finder

## Short description (132 characters max — currently 98)
Before you buy a book online, see if you can borrow it free through Open Library or your local library.

## Detailed description

Library Finder catches you before you buy a book online and shows you a free way to read it instead.

When you land on a book's page on Amazon, a small banner appears with one of two things:

- If the book is available to borrow free online through Open Library, a direct link to borrow it.
- If not, a link to search for that exact book (by ISBN, not a guess from the title) so you can check whether your local library has it.

No account, no sign-up, nothing to configure. If the page isn't a book, the extension does nothing.

Library Finder reads only the page's visible text to detect an ISBN, and sends only that ISBN to Open Library's free public API. It doesn't collect, store, or track anything about you. Full privacy policy: https://github.com/aribajahan/library-finder/blob/main/PRIVACY.md

Currently supports: Amazon
Source code: https://github.com/aribajahan/library-finder
